# TL;DR（3行）
- 生成AI（LLM）を活用してサイバー欺瞞戦略（deception ploy）を自動生成するフレームワークSPADEを提案
- 構造化プロンプトエンジニアリング（PE）により、汎用LLMからマルウェア対策に特化した実用的な欺瞞戦術を生成
- ChatGPT-4oが最高性能（エンゲージメント率93%、精度96%）を達成し、Gemini・Llama3.2も競争力ある結果

# Problem / Setting
- 入力/出力: マルウェアのサンドボックス解析結果（TTP: 戦術・技術・手順）を入力し、適応的な欺瞞戦術（honeyfile, API hook, honeytoken等）を出力
- 目的: 攻撃者を欺き、遅延させ、偽の資産に誘導することでマルウェアの深層分析を可能にする
- 評価指標: Recall, Exact Match (EM), BLEU Score, エンゲージメント率, 精度, 反復回数, 応答時間
- 制約: 生成された欺瞞戦術は実運用環境で展開可能であること、正規システム機能に影響を与えないこと
- 比較対象: 従来の静的honeypot/honeytoken生成、手動設定による欺瞞戦略

# Key Contributions
- [GenAIによるサイバー欺瞞の包括的評価]: ChatGPT-4o, ChatGPT-4o Mini, Gemini, Llama3.2の比較 → Recall 85.7-90.6%, EM 80.6-90.3%
- [静的honeypotを超えた多様な欺瞞戦術の自動生成]: honeyfile, API hook, honeytokenなど多層的戦術 → 15種のマルウェアサンプルで実証
- [SPADEフレームワーク]: 6コンポーネント（Identity, Goal, Threat Context, Strategy Outline, Output Example, Output Format）の構造化PE → 一貫した展開可能出力

# Method
- 前処理: 既存防御機構によるマルウェア検出後、サンドボックス解析でTTP（戦術・技術・手順）を抽出
- コアアルゴリズム: SPADE構造化プロンプト（6コンポーネント）でLLMに文脈特化の欺瞞戦術を生成させる
  - Identity/Persona: サイバーセキュリティ専門家の役割を指定
  - Goal/Task: 具体的なタスク（例: credential-stealing malware向けhoneytoken生成）を明示
  - Threat Context: サンドボックス解析結果、観測されたTTP、攻撃パターンを記述
  - Strategy Outline: 運用制約（リソース効率重視等）を指定
  - Output Example: Few-shot promptingで理想的な出力例（JSON, 擬似コード等）を提供
  - Output Instructions: 出力フォーマット（JSON, XMLなど）を指定
- 学習手順: 学習不要（既存LLMをプロンプトで誘導）
- 推論手順: Prompt Generator → LLM → 複数の欺瞞戦術候補生成 → 専門家選択 → 展開ガイダンス生成

# Experiments
- Dataset / Benchmark: 94種の悪意あるAPIシーケンス、31種のマルウェア行動、MITRE ATT&CKマッピング（先行研究[7]より）
- Metrics: Recall, Exact Match (EM), BLEU Score（技術的整合性・言語品質）、エンゲージメント率、精度、反復回数、応答時間
- Baselines: 通常プロンプト（非構造化）との比較、手動作成の欺瞞戦術（ground truth）との比較
- Setup: 3種のマルウェアシナリオ（ransomware, credential-stealer, keylogger）×5インスタンス=15サンプル、仮想環境でのテスト

# Results（主要数値）
- ChatGPT-4o: Recall 90.6%, EM 87.1%, BLEU 0.968、エンゲージメント率93%、精度96%、反復1.67回、応答12.3秒
- Gemini: Recall 88.6%, EM 83.9%, BLEU 0.935、エンゲージメント率93%、精度93%、反復2.47回、応答15.1秒
- ChatGPT-4o Mini: Recall 86.4%, EM 80.6%, BLEU 0.935、エンゲージメント率88%、精度91%、反復2.22回、応答8.58秒
- Llama3.2: Recall 85.7%, EM 90.3%, BLEU 0.871、エンゲージメント率85%、精度89%、反復2.89回、応答15.8秒
- 専門家評価（構造化PE使用、ChatGPT-4o）: Relevance 4.3-4.8, Actionability 4.1-4.6, Feasibility 4.0-4.7, Realism 3.9-4.5（5点満点）

# Ablations / Analysis
- 構造化PE vs 通常プロンプト: 構造化PEで4次元（relevance, actionability, feasibility, realism）全てで大幅向上
- 効いたコンポーネント: Threat Context（マルウェア固有情報）とOutput Example（Few-shot）が特に重要
- Llama3.2はEM高い（90.3%）がRecall・BLEUが低く、特定ケースでの精度は高いが汎用性に課題

# Limitations / Risks
- 再現性: GitHubリポジトリ[27]で公開、ただしLLM API依存のため再現性に課題あり
- 外的妥当性: 3種のマルウェアタイプ、15サンプルのみ。実環境での検証なし
- 計算コスト: LLM API呼び出しコスト、応答時間8.58-15.8秒
- 評価の穴: 敵対的テスト（攻撃者がLLM生成欺瞞を見破るケース）未実施、長期運用での効果未検証

# Relation to Prior Work
- 従来のhoneypot/honeytoken研究は静的・手動設定が主流（Provos 2004, Kyung 2017）
- CHIMERA, SODA等の動的欺瞞システムは事前定義ルールベースで適応性に限界
- LLMベースのhoneypot研究（shelLM, ChatGPT honeypot）は存在するが、静的リソース生成に留まる
- 本研究は多層的・適応的欺瞞戦術の自動生成まで拡張
