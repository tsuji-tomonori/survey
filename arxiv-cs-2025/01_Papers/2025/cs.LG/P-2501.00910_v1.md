# TL;DR（3行）
- 既存のTS生成モデルは個別サンプルの品質に注力するが、データセット全体の**母集団レベル特性**（値分布、次元間相関分布）の保存を軽視
- PaD-TSは**Population Aware Training (PAT) 損失**と**Same diffusion Step Sampling (SSS)**、**Dual-channel encoder**で母集団レベル特性を明示的に保存
- FDDSで5.9倍、VDSで5.7倍の改善を達成しつつ、個別真正性は同等を維持

# Problem / Setting
- **入力**: 多変量時系列データセット $\mathcal{D}_{orig} = \{x_n\}_{n=1}^N$、各サンプル $x \in \mathbb{R}^{L \times F}$（L: 系列長、F: 特徴数）
- **出力**: 合成データセット $\mathcal{D}_{syn}$
- **目的**: 個別レベル（サンプル単位）の真正性と、母集団レベル（データセット全体）の特性分布を両方保存
- **評価指標**:
  - **DA (Discriminative Accuracy)**: 分類器がreal/syntheticを識別できない度合い（0に近いほど良い）
  - **VDS (Value Distribution Shift)**: 各次元の値分布のKLダイバージェンス平均
  - **FDDS (Functional Dependency Distribution Shift)**: 次元間の相互相関（Cross-Correlation, CC: 2つの時系列間の時間遅れを考慮した相関係数）分布のシフト
  - **Predictive score**: 合成データで訓練したRNNの予測MAE
- **制約**: 母集団レベル特性（例: 外気温とキッチン温度のCC分布）を保存しないと、下流タスクでバイアス発生
- **比較対象**: Diffusion-TS (ICLR 2024)、TimeGAN (NeurIPS 2019)、TimeVAE

# Key Contributions
- [PAT損失]: MMDで合成・元データの機能依存分布距離を正則化 → FDDSで5.9倍改善の根拠
- [SSS戦略]: ミニバッチ内で同一拡散ステップをサンプル → 意味のある分布比較を可能に
- [Dual-channel architecture]: temporal channelとcross-dim channelを分離し、DiTブロックで統合 → 次元間特徴の明示的抽出

# Method
- **前処理**: 時系列を[-1, 1]に正規化
- **コアアルゴリズム**:
  1. **Dual-channel encoder**:
     - Temporal channel: $h_T = (W_T x_T + b_T) + pos(x_T)$ → Transformer Encoder → DiTブロック
     - Cross-dim channel: $h_D = W_D x_D + b_D$ → Transformer Encoder → DiTブロック
     - 最終出力: 両チャネルのDiTブロック出力を加算
  2. **PAT損失**: $\mathcal{L}_{total} = \mathcal{L}_0 + \alpha \cdot \mathcal{L}_{pop}$
     - $\mathcal{L}_{pop} = \frac{1}{M} \sum_{m=1}^M \text{MMD}_W(P_{CC}^{i,j}, Q_{CC}^{i,j})$
     - RBFカーネルを複数ウィンドウサイズで使用
  3. **SSS**: $t = [t_1, t_1, ..., t_1]$（バッチ内で同一ステップ）
- **学習手順**: AdamW (lr=0.0001)、cosineノイズスケジューラ、250-500拡散ステップ
- **推論手順**: 標準DDPMのreverse process、拡散ステップから逐次ノイズ除去

# Experiments
- **Dataset / Benchmark**: Sines（合成）、Stocks（Google株価、5特徴）、Energy（家庭エネルギー消費、28特徴）、Mujoco、fMRI
- **Metrics**: VDS、FDDS、DA、Predictive score、MDD、ACD、SD、KD、ED、DTW
- **Baselines**: Diffusion-TS、TimeGAN、TimeVAE
- **Setup**: AMD EPYC 7313 CPU、128GB RAM、2x NVIDIA A40、系列長24/64/128/256

# Results（主要数値）
- **FDDS (系列長24)**: PaD-TS 0.0003/0.0588/0.0442 vs Diffusion-TS 0.0031/0.1841/0.1837（Sines/Stocks/Energy）→ 平均5.9倍改善
- **VDS (系列長24)**: PaD-TS 0.0005/0.0029/0.0019 vs Diffusion-TS 0.0007/0.0369/0.0060 → 平均5.7倍改善
- **DA (系列長24)**: PaD-TS 0.013±0.004/0.055±0.087/0.078±0.011 vs Diffusion-TS 0.005±0.000/0.082±0.025/0.127±0.016 → 同等（Sinesのみやや劣る）
- **長系列(Energy)**: 系列長256でDA 0.138±0.174 vs Diffusion-TS 0.393±0.009 → 3.4倍改善
- **訓練時間**: PaD-TS 77/75/117min vs Diffusion-TS 17/15/60min（約2倍長い）

# Ablations / Analysis
- **各コンポーネントの効果（FDDS on Energy）**:
  - Full PaD-TS: 0.0442
  - w/o Temporal: 0.5254（最重要）→ 時間方向の特徴抽出がFDDS保存の根幹
  - w/o SSS: 0.3626（2番目に重要）→ 異なる拡散ステップ混在でMMD計算が無意味化
  - w/o PAT: 0.0816 → PAT損失なしでも構造が効く（ただし改善幅は限定的）
  - w/o Dimension: 0.0533 → 次元間チャネルの寄与は相対的に小さい
- **αの影響**: α増加でFDDS改善・VDS悪化のトレードオフ、α=0.05で訓練崩壊
- **最適α**: Sines 0.0005、Stocks 0.0008、Energy 0.0005

# Limitations / Risks
- **再現性**: コード公開あり (https://github.com/wmd3i/PaD-TS)、ハイパーパラメータ詳細あり
- **外的妥当性**: 3+2データセットで検証、ただし実世界の複雑なTSでの検証は限定的
- **計算コスト**: 訓練時間約2倍増（PAT損失のペアワイズ計算、SSSによるエポック増が原因）
- **評価の穴**: CCのみを機能依存として検証（mutual informationなど他の依存関係は未検証）
- **αの選択**: データセットごとにチューニング必要、汎用的な設定ガイドラインなし

# Relation to Prior Work
- **GANベース (TimeGAN等)**: 訓練不安定、mode collapse問題
- **VAEベース (TimeVAE等)**: ELBO最適化による品質低下、mode collapse
- **Diffusionベース (Diffusion-TS)**: 個別レベル品質は高いが、母集団レベル特性保存を明示的に考慮せず
- **InfoVAE**: 潜在空間での分布シフトをペナルティ化（画像生成）→ 本手法はDMの反復的生成に対応

# My Notes（解釈・疑問・使い道）
- **解釈**: 母集団レベル特性の保存は、合成データの「統計的一貫性」の問題。下流タスク（予測、異常検知）でのバイアス軽減に重要
- **疑問**: SSSで拡散ステップのカバレッジが減るが、エポック増でカバーするという主張の定量的検証がない
- **使い道**: プライバシー保護が必要なヘルスケア・エネルギー分野での合成データ生成、データ拡張
