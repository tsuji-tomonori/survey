# TL;DR（3行）
- 唇の静的形状ではなく動的な調音運動（articulator dynamics）に基づく形状非依存の連続認証システムを提案
- 3階層の特徴階層（Basic/Intermediate/Advanced）を構築し、唇テクスチャの動きと音素発話時の口の開き方パターンを抽出
- 50名のデータセットで99.06%の精度を達成し、mimic攻撃・deepfake攻撃に対しても高いロバスト性を実証

# Problem / Setting
- 入力/出力: 唇領域の動画（発話中）→ 正規ユーザーか攻撃者かの二値分類
- 目的: 顔全体を使わずプライバシーに配慮した連続認証を実現
- 評価指標: Accuracy, Precision, Recall, F1-score, 攻撃成功率
- 制約: VR/スマートカー等のハンズフリー環境、発話中の動的状態と静止状態の両方に対応が必要
- 比較対象: 静的唇認証（形状ベース）、SALM, SilentKey, LipAuth等の動的唇認証

# Key Contributions
- [形状非依存特徴]: 唇の溝・リッジパターンの動きを追跡し、形状変化（化粧・表情）に依存しない特徴を抽出 → リップスティック境界変更実験で従来手法を大幅に上回る
- [3階層特徴階層]: Basic（形状）/Intermediate（GLCM+ガウス微分フィルタ）/Advanced（動的調音特徴）の階層的特徴設計 → 静的のみ/動的のみの手法より高精度
- [音素ベース口開き分類]: 発話時の口の開き方をsmall/medium/largeの3カテゴリに分類し、個人固有の発話パターンを捕捉 → 連続認証を可能に
- [50名データセット]: IoTコマンド発話を含む設計されたパスフレーズデータセットを収集、公開予定

# Method
- 前処理: dlibで68ランドマーク検出 → 唇領域（48-67番、20点）を多項式曲線でフィッティング → ROI抽出
- コアアルゴリズム:
  - Basic Level: 面積、周長、厚さ等の静的形状特徴
  - Intermediate Level: 唇を6領域（UL,UM,UR,LL,LM,LR）に分割し、ガウス微分フィルタ（8方向）→ GLCM特徴（ASM, Contrast, Correlation, IDM, Entropy）→ PCAで2次元に削減
  - Advanced Level:
    - 形状非依存特徴: CLAHE→Canny→bilateral filter→Hough変換で唇溝検出→フレーム間の動きベクトル計算
    - 調音特徴: 20ランドマークの時系列座標から相関係数行列を構築
- 学習手順: Siamese Network（2つの同一CNN）、contrastive lossで学習
- 推論手順: ユーザープロファイルとの特徴ベクトル間のユークリッド距離を計算、閾値判定

# Experiments
- Dataset / Benchmark: 自作データセット、50名（女性22、男性28）、IoT音声コマンド30フレーズ×5回繰り返し
- Metrics: Accuracy, Precision, Recall, F1-score, PR曲線
- Baselines: 静的唇特徴のみ、動的特徴なし（Intermediate Level）の2つのアブレーション
- Setup: SONY 4K 25fps + 各種スマホカメラ（iPhone11, Redmi K60, HUAWEI等）、200lux照明、10-fold cross-validation

# Results（主要数値）
- 全体精度: Accuracy 99.06%（median 99.47%）, Precision 99.26%, Recall 98.93%, F1 99.09%
- Mimic攻撃成功率: 0.37%（49名が1名をなりすまし）
- Advanced Mimic攻撃（写真利用）成功率: 0.68%
- AI Deepfake攻撃成功率: 1.72%
- 静的特徴のみ: 精度約10%程度（Fig.16より）、提案手法は99%超で大幅改善
- カメラ種類・角度（±45°）・照明（80-500lux）・リップ状態による影響: 概ねAccuracy 85-95%以上を維持

# Ablations / Analysis
- 効いたコンポーネント: Advanced Level特徴（形状非依存+調音特徴）が最も重要、これなしでは精度大幅低下
- 8ニューロン構成が2, 4ニューロンより良好なPR曲線トレードオフ
- リップスティック境界外塗布実験: 形状依存手法は精度低下、提案手法は維持
- 効かない条件: リップスティックで唇境界を変更した場合でも約85%以上維持（ただし若干低下）

# Limitations / Risks
- 再現性: コード・データセット公開予定（acceptance後）、現時点では未公開
- 外的妥当性: 50名のみ、特定環境（室内、制御された照明）での評価に限定
- 計算コスト: 推論時間の記載なし、リアルタイム性能の検証が不明
- 評価の穴:
  - 既存の動的唇認証手法（SALM, SilentKey, LipAuth）との直接比較なし
  - 長期間使用での特徴安定性未検証
  - 極端な照明条件（屋外等）未評価

# Relation to Prior Work
- 静的唇認証（Hough変換、VGG16/19等）: 形状変化に弱い問題を動的特徴で解決
- SALM: パスワード併用で連続認証不可 → 本手法は連続認証可能
- SilentKey: 超音波利用で環境ノイズに敏感 → 本手法はカメラベースで環境依存低
- LipAuth: 笑顔動作のみ → 本手法は発話中の多様な動作に対応

# My Notes（解釈・疑問・使い道）
- VR/車載認証等のハンズフリー連続認証に有望だが、実デバイス実装・消費電力等の実用性検証が必要
- Deepfake攻撃への耐性1.72%は興味深いが、より高度なリップシンク生成技術への耐性は要検証
- 唇テクスチャの経年変化や健康状態による影響は未検討
