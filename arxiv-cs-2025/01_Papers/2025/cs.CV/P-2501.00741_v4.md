# TL;DR（3行）
- 単眼イベントカメラから物理的事前知識（カメラ軌道等）なしでEnd-to-Endのボクセル3D再構成を実現
- Sobel Event Frame（エッジ強調表現）+ ECA付きResNet-152エンコーダで特徴学習を強化
- ベースラインE2Vに対してmIoU 54.6%改善。ただし従来の画像ベース手法とは依然差があり、イベント単眼としての改善に留意

# Problem / Setting
- 入力/出力: イベントストリーム（512×512、0.5秒間のスキャン）→ 32×32×32のボクセルグリッド
  - Event Frame: 時間窓内のイベントを2D画像に蓄積した表現（各ピクセルはイベント発生回数や極性を符号化）
- 目的: 単眼イベントカメラからの物理的事前知識（カメラ姿勢、視差情報）不要のEnd-to-End 3D再構成
- 評価指標: mIoU（Mean Intersection over Union）、F-Score
- 制約: 従来手法は複雑なパイプライン（イベント表現→事前推定→視差計算→三角測量→深度推定→3D再構成）を必要とし、物理的事前知識が必須
- 比較対象: E2V（Chen et al., 2023）- 初のボクセルベース3D再構成手法、mIoU 0.346

# Key Contributions
- [Sobel Event Frame]: Event Frameにソーベルフィルタを適用しエッジを強調 → E2Vモデルで31.6%改善（0.358→0.471）
- [ECA付き3D ResNet-152エンコーダ]: 各ボトルネック層後にEfficient Channel Attentionを統合 → Event Frame(Pos)で17.6%改善（0.358→0.421）
- [Optimal Binarization Threshold Selection Principle]: 出力二値化閾値の最適化ガイドライン → 固定閾値（0.20）より最適閾値（0.34）で性能向上

# Method
- 前処理: イベントストリームを5.0×10⁻³秒の時間窓で100フレームに分割、Sobel Event Frameでエッジ強調、[0,1]正規化後(n,256,256)にリサイズ
- コアアルゴリズム:
  - Sobel Event Frame: Event Frameに3×3ソーベルカーネルを畳み込み、勾配強度を[0,255]に正規化
  - O(x,y,t) = Σ E(x+w, y+h, t) · S(w,h) （ソーベル畳み込み）
  - 5つのEvent Frameモード（Pos/Neg/Last/Any/Sep）に対応
- 学習手順:
  - エンコーダ: ResNet-152ベースの3D CNN、各ボトルネック層（3,8,36,3ブロック）後にECAモジュール統合
  - ECA: Global Average Pooling → 1D Conv（適応的カーネルサイズ）→ Sigmoid
  - 損失関数: Focal Loss（不均衡データ対応）
  - Adam optimizer (lr=1.0×10⁻⁶, β=(0.9,0.999))、100エポック、バッチサイズ5、Dropout 0.25
- 推論手順: logit出力 → Sigmoid → 最適閾値p*で二値化（閾値は0.15-0.50の範囲で0.01刻みで探索）

# Experiments
- Dataset / Benchmark: SynthEVox3D（39,739サンプル、13カテゴリ、ShapeNet由来）、SynthEVox3D-Tiny（1,040サンプル、832訓練/104検証/104テスト）
- Metrics: mIoU、F-Score（カテゴリ別・全体平均）
- Baselines: E2V（Chen et al., 2023）、3D-R2N2、AttSets、Pix2Vox++、EVolT（従来画像ベース手法との参考比較）
- Setup: 入力解像度512×512→256×256、時間窓5ms×100フレーム、出力ボクセル32×32×32

# Results（主要数値）
- mIoU 0.523（Tiny）/ 0.535（Full）: E2V 0.358/0.346に対して46.1%/54.6%改善、閾値0.34
- F-Score 0.682: E2V 0.507に対して34.5%改善
- カテゴリ別最高: Rifle 0.610、Cabinet 0.617、Watercraft 0.607（Sobel EvtFrm Pos）
- 従来画像手法との比較: 3D-R2N2(0.636)、AttSets(0.693)、Pix2Vox++(0.706)、EVolT(0.735)よりは低いが参考比較として提示

# Ablations / Analysis
- 効いたコンポーネント:
  - Sobel Event Frame単独: +31.6%（0.358→0.471）
  - ECA付きモデル単独: +17.6%（0.358→0.421）
  - 組み合わせ: +46.1%（0.358→0.523）
- 閾値の影響: 0.34が最適、0.16では-0.035のmIoU低下
- Event Frameモード: Pos/Anyが最良（負データなしモード）、Neg/Last/Sepは現設定で劣る
- 効かない条件: 負極性を含むモードは現実験設定では性能低下

# Limitations / Risks
- 再現性: コード公開状況不明、データセットSynthEVox3Dは既存（ShapeNet由来の合成データ）
- 外的妥当性: 合成データのみで評価、実環境イベントカメラデータでの検証なし
- 計算コスト: ResNet-152ベース + ECA、具体的な推論時間・メモリ使用量の記載なし
- 評価の穴: 従来画像手法との比較はデータセット・条件が異なり直接比較困難、極端条件（高速動作、低照度、高輝度）での評価は今後の課題
- **閾値最適化リスク**: 最適閾値（0.34）がテストセットで選択されており、過適合の可能性あり。新規データでの汎化性能は要検証
- ResNet-152の事前学習: ImageNet事前学習の有無が論文中で明示されていない

# Relation to Prior Work
- E2V（Chen et al., 2023）: ボクセルベース3D再構成の初手法、本研究のベースライン
- 物理ベース手法（Kim 2016, EVO, EMVS, EVI-SAM）: カメラ軌道等の物理的事前知識が必須、複雑なパイプライン
- 深層学習手法（E3D, Xiao 2022, Wang 2024）: 依然として物理的事前知識やパイプラインが必要
- ECA-Net（Wang et al., 2020）: Efficient Channel Attentionの元論文、本研究で3D CNNに適用

# My Notes（解釈・疑問・使い道）
