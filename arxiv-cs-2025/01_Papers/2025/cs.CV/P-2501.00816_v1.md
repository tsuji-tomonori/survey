# TL;DR（3行）
- 参照スケッチ画像のスタイルを自然画像に転写し、訓練なしでスケッチを抽出する手法
- Stable DiffusionのSelf-Attention層で参照画像とターゲット画像の特徴を混合（MixSA）
- 追加学習不要で多様なスケッチスタイル（鉛筆画、線画等）に対応

# Problem / Setting
- 入力/出力: 自然画像 + 参照スケッチ画像 → ターゲット画像のスケッチ（参照スタイル）
- 目的: 参照画像のスケッチスタイルをターゲット画像に転写
- 評価指標: スケッチの視覚的品質、スタイル一致度（ユーザースタディ、定性評価）
- 制約: 追加学習なし（Training-free）、事前学習済みStable Diffusion使用
- 比較対象: 学習ベースのスケッチ抽出手法、エッジ検出手法

# Key Contributions
- [MixSA機構]: Self-Attention層で参照・ターゲット画像のK/V特徴を混合 → 訓練不要でスタイル転写
- [Training-free]: 事前学習済みモデルのみ使用 → 新規データ収集・学習不要
- [柔軟なスタイル対応]: 1枚の参照画像で多様なスケッチスタイルに対応 → few-shot/zero-shot設定

# Method
- 前処理: ターゲット自然画像と参照スケッチ画像を入力
- コアアルゴリズム: Stable DiffusionのSelf-Attention層を改変
  - 通常のSelf-Attention: Q, K, V全て同一画像特徴量から計算（Attention(Q,K,V) = softmax(QK^T/√d)V）
  - MixSA: Qはターゲット画像から、K/Vは参照スケッチ画像と混合して計算
  - 効果: ターゲット画像の「どこに注目するか」(Q)を保持しつつ、「何を参照するか」(K/V)を参照スケッチから借用
  - これにより参照画像のスタイル情報（線の太さ、質感等）がターゲットの構造に転写される
- 学習手順: 不要（事前学習済みSD系モデルをそのまま使用）
- 推論手順: SDXLやSD系モデルの拡散過程中にMixSAを適用、逆拡散でスケッチ生成
  - 適用レイヤー/ステップの詳細はPDF参照必要
