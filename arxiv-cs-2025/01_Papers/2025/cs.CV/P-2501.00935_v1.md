# TL;DR（3行）
- 動的ハンドジェスチャー認識のためのMultiscaled Multi-Head Attention Video Transformer Network（MsMHA-VTN）を提案
- 各Attentionヘッドで異なる次元（ピラミッド構造）を持たせ、マルチスケール特徴を抽出
- NVGesture 88.22%、Briareo 99.10%でSOTA達成（マルチモダリティ入力時）

# Problem / Setting
- 入力/出力: ジェスチャー動画（RGB, Depth, IR, Surface Normals※, Optical Flow）→ ジェスチャークラスラベル
  - ※Surface Normals: 深度画像から推定した各画素の法線ベクトル（3D形状情報を2D表現に変換）
- 目的: 動的ハンドジェスチャーの高精度分類
- 評価指標: 認識精度（Accuracy）
- 制約: 40フレーム/シーケンス、ResNet-18（ImageNet事前学習）をバックボーンに使用
- 比較対象: 基本Transformer [12]、R3D-CNN、I3D、MTUT、NAS系手法

# Key Contributions
- [MsMHA]: 各ヘッドで異なる次元のAttention（N, N/2, N/4...N/128）を持つピラミッド構造 → 従来の同一次元MHAより高精度（Normals単体で86.21% vs 82.40%）
- [マルチモダリティ対応]: RGB, Depth, IR, Normals, Optical Flowの組み合わせで後期融合 → 5モダリティで最高精度88.22%
- [Surface Normalsの有効性発見]: Depthから推定したSurface Normalsが単一モダリティで最も高精度 → NVGesture 86.21%、Briareo 98.67%

# Method
- 前処理: 各フレームをResNet-18で特徴抽出、40フレーム/シーケンス
- コアアルゴリズム:
  - 8ヘッドのAttentionで、各ヘッドの次元をL×D, L×D/2, L×D/4...L×D/128とピラミッド状に減少
  - Attention(Q,K,V) = softmax(QK^T/√dk)V を各ヘッドで計算後、Concat
  - 6段のTransformerステージ（T1-T6）を積層
- 学習手順: Adam optimizer、初期学習率1e-4、50/75エポックで減衰
- 推論手順: 各モダリティで独立に分類スコア計算 → 後期融合（スコア加算のargmax）

# Experiments
- Dataset / Benchmark: NVGesture（25クラス、運転中ジェスチャー）、Briareo（12クラス、車内ジェスチャー）
- Metrics: Top-1 Accuracy
- Baselines: R3D-CNN、I3D、Transformer [12]、MTUT、NAS1/NAS2、C3D等
- Setup: PyTorch 1.6.0、Nvidia Tesla K80 GPU（24GB）、CUDA 10.1

# Results（主要数値）
- NVGesture単一モダリティ: Normals 86.21%（+3.81% vs Transformer）、Depth 85.00%（+2% vs Transformer）、Optical Flow 85.30%（+13.3% vs Transformer）
- NVGesture 5モダリティ融合: 88.22%（vs NAS1+NAS2 88.38%と同等）
- Briareo単一モダリティ: Normals 98.67%（+2.87% vs Transformer）
- Briareo 3モダリティ（Color+IR+Normals）: 99.10%（+1.9% vs Transformer最高97.20%）

# Ablations / Analysis
- モダリティ数増加の効果: NVGestureで1→2→3→4→5モダリティで70-86%→84-88%→85-88%→85-88%→88.22%と漸増
- Surface Normalsの重要性: Depthより情報量が多く、単体で最高精度
- 2モダリティ以上では精度改善が頭打ち（Briareoでは3モダリティ以上で改善なし）

# Limitations / Risks
- 再現性: コード非公開、ハイパーパラメータの詳細不足（バッチサイズ、エポック数等）
- 外的妥当性: NVGestureとBriareoの2データセットのみ、他ドメインへの汎化未検証
- 計算コスト: FLOPs/パラメータ数/推論速度の比較なし
- 評価の穴: Human baseline（88.40%）に達していない（NVGesture Color）、分散/信頼区間なし

# Relation to Prior Work
- 基本TransformerモデルのMHA [5]を拡張し、各ヘッドで異なる次元を使用するMsMHAを提案
- MViT [10,11]がPoolingでマルチスケール化するのに対し、本手法はAttention次元でマルチスケール化
- D'Eusanio et al. [12]のTransformerベースジェスチャー認識を改良

# My Notes（解釈・疑問・使い道）
- アイデア自体はシンプル（ヘッドごとに次元を変える）だが、ジェスチャー認識では有効
- Surface Normalsが有効という知見は他のRGB-Dタスクにも応用可能か
- 計算コストの増減が不明（次元減少でFLOPs減？Concat後のW_Oで増？）
- 後期融合のみで、中間特徴の融合は未探索
