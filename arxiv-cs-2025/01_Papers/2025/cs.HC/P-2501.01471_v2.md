# TL;DR（3行）
- ウェアラブルECGでスピーチ活動前後のHR（心拍数）/HRV（心拍変動）を4フェーズ（ベースライン・予期・活動・反省）で測定
- SAD（社会不安障害）群はnon-SAD群より全フェーズで低HRV・高HRを示し、RMSSD, S, SD1が有意な識別マーカー
- インド（LMIC: 低中所得国）での初の制御実験、公開データセットを提供

# Problem / Setting
- 入力: ECG信号（Shimmer ECG、1024Hz）、SPINスコア（社会不安重症度）、PAL（知覚不安レベル）
- 出力: 時間・周波数・非線形HRV特徴量、SAD/non-SAD分類
- 目的: 社会不安障害（SAD）の客観的生理マーカー特定、ウェアラブル検出の可能性検証
- 評価指標: HRV/HR特徴量の群間差（SAD vs non-SAD）の統計的有意性（p値、効果量）
- 制約: ラボ環境での制御実験、非臨床サンプル（大学生）、SPINスコア閾値20でSAD分類
- 比較対象: 先行研究（主に欧米での単一フェーズ研究）との整合性検証

# Key Contributions
- [3フェーズ分離分析]: 予期・活動・反省を個別に分析 → 従来の単一時点比較を超えた時間的動態把握
- [LMIC初の公開データセット]: インドでの初のSAD-HRV制御実験データをOSFで公開 → Global South研究の基盤提供
- [SD1の新規マーカー提案]: 非線形HRV指標SD1がSAD識別に有効 → 従来RMSSD/HFに偏重していた研究の拡張

# Method
- 前処理: FIRバンドパスフィルタ（1-49Hz）、Hamilton SegmenterでRピーク検出
- 実験設計: 4フェーズ（ベースライン2分→予期45秒→スピーチ2.5分→反省45秒）、3人1組でスピーチ
- 特徴抽出: Neurokit2でtime/frequency/nonlinear HRV特徴（SDNN, RMSSD, HF, SD1, SD2等17種+HR）
- 分析手法: 階層線形モデル（HLM）、phase固定効果・group/gender/location等ランダム効果
- 群分類: SPINスコア>20をSAD、≤20をnon-SADに分類

# Experiments
- Dataset / Benchmark: 自作データセット、99人募集→51人分析（48人はノイズで除外）
- Metrics: HRV特徴量の群間・フェーズ間差（p値: *0.05, **0.01, ***0.001）
- Baselines: 先行研究（Alvares 2013, Rubio 2017, Tolin 2021等）との比較
- Setup: Shimmer ECG（臨床グレード）、インドIISER Bhopal学生、SAD31人/non-SAD20人

# Results（主要数値）
- RMSSD: SAD群で有意に低下（p<0.05）、既存文献[2,4,21,11]と一致
- S（Poincaréプロット面積）: SAD群で有意に低下（p<0.05）、新規発見
- SD1: SAD群で有意に低下（p<0.05）、非線形指標として初の有意な識別マーカー
- PAL: 予期・活動フェーズで有意に上昇（p<0.001）、SAD群はnon-SADより有意に高い（p<0.01）
- 効果量: SAD vs non-SAD群のSPINスコア差のCohen's d = 2.68（大きな効果）

# Ablations / Analysis
- 性別効果: 女性は男性より低HRV・高HR、性別固定効果追加でTINN, SD2も有意マーカーに
- 相関分析: HRVとSPIN/PALは負の相関、特に女性で相関が強い
- フェーズ別変化: 予期・活動でHRV低下・HR上昇、反省でHRV回復（MeanNN, MedianNN, HF等）
- HF特異性: ベースライン・予期・反省ではSPIN/PALと負相関だが、活動中は正相関（要追究）

# Limitations / Risks
- 再現性: データセット公開（OSF）、Neurokit2使用で再現可能だが48/99人データ除外は課題
- 外的妥当性: 非臨床サンプル（SPIN分類）のため臨床的SAD診断と異なる可能性
- 計算コスト: 臨床グレードECG使用、PPG（スマートウォッチ）での検証が今後必要
- 評価の穴: 女性参加者33%で性差分析の検出力限定、認知的変化（自己批判等）は未測定

# Relation to Prior Work
- 先行研究（主に欧米）ではHRV/HR結果が混在（有意減少[2,3,4] vs 非有意[5,6,7,8]）
- 本研究はLMIC初、3フェーズ分離分析により時間的動態を捉えた点で新規
- RMSSD, HFは既存研究と一致、SD1は本研究が初めて有意なSADマーカーとして報告

# My Notes（解釈・疑問・使い道）
- ウェアラブル（PPG）への展開可能性が示唆されているが、PPGでのHRV精度検証が必要
- 予期フェーズで最も不安が高いという知見は介入設計に重要（活動前の支援が効果的）
- 非線形指標（SD1, S）の有効性はDNN/SSL等の表現学習でも活用可能か？
- Global South研究の文脈的妥当性の議論が充実、ICTD/COMPASS系に参考になる
